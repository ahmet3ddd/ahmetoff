YouTube'da aç
Türkçe altyazı kendiliğinden açılır. Açılmazsa oynatıcıda ⚙ → Altyazılar → Otomatik çevir → Türkçe. Videonun Türkçe seslendirmesi varsa ⚙ → Ses parçası menüsünde çıkar.

Tercihler

API anahtarı

Akış, kendi YouTube Data API anahtarınla çalışır. Ücretsiz; günde 10.000 birim kotası var.

  1. console.cloud.google.com adresinde yeni proje aç
  2. "YouTube Data API v3"ü etkinleştir
  3. Kimlik bilgileri → API anahtarı oluştur
  4. Anahtarı bu API ve bu sayfanın adresiyle kısıtla

Türkçe seslendirme

Altyazısı olmayan videolar için Türkçe altyazıyı ve Türkçe seslendirmeyi bilgisayarındaki Seçki Dublaj servisi hazırlar. Telefondan da çalışır; yalnızca bilgisayarın açık olması yeter.

Kurulum için bilgisayarındaki terminale bunu yapıştır:

bash <(curl -fsSL https://ahmetoff.com/ahmetoff/projects/secki/dublaj/install.sh)

Telefona aktar

Bilgisayarda anahtarı ve tercihleri girdikten sonra QR kodu göster, telefonun kamerasıyla okut. Telefonda sayfa açılır, anahtar ve tercihler kendiliğinden yerleşir.

Takip ettiğim kanallar

Kanal adresi, @kullanıcıadı ya da UC… kimliği yapıştır. Kanal başına yenileme 1 birim.

İlgi konuları

Her konu YouTube aramasıyla akışa video getirir. Arama 100 birim; sonuçlar 6 saat saklanır.
