Nasıl Kullanılır

Bu tek dosyalı HTML çift tıklanıp tarayıcıda doğrudan açılabilir. Three.js otomatik olarak internetten yüklenir.

1. V8 Tipi Seçin

V8 … 1 (orijinal 7_8_1.ms): üçgen tepe formlu, 4 vertex / 3 face per yarım.
V8 … 2 (orijinal 7_8_2.ms): 7-vertex yıldız form, aynalı kopyasıyla beraber tekrarlanır. Yükseklik (W/2)/tan(30°) ile otomatik.

2. Parametreler

  • Mesafe: Orijinaldeki seçilen line'ın uzunluğu.
  • Genişlik: Tek bir kalıp genişliği (asa). Mesafeye sığacak şekilde otomatik snap edilir.
  • Yükseklik / A / B / C: Orijinal spn32, spn24, spn28, spn13 spinner karşılıkları.

3. Görünümler

Sol viewport 2D Ön Görünüm (XZ düzlemi). Sağ viewport 3D Three.js: sol tuş orbit, orta tuş pan, tekerlek zoom.

4. Export

  • STL: 3D mesh, kapatıcı arka yüzlerle birlikte.
  • DXF: 2D ön görünüm wireframe (R12 / AC1009).
  • PNG: Aktif viewport'un (2D veya 3D) görüntüsü.
