# Yedi-Sekiz (7-8)

Geleneksel yedi-sekiz geçme desenlerini parametrelerle 2B ve 3B üreten, tarayıcıda çalışan bir tasarım aracı.

**▶ Canlı demo:** https://ahmet3ddd.github.io/ahmetoff/projects/AI_7-8/

<img src="../../assets/shot-7-8.png" alt="Yedi-Sekiz (7-8)" width="100%" />

## Özellikler

- V8 tipleri: **yedisekiz1** ve **yedisekiz2**
- Ayarlanabilir parametreler: mesafe (çizgi), genişlik, yükseklik, A, B, C
- 2B ön görünüm (XZ) ve 3B model
- **DXF**, **STL** ve **PNG** olarak dışa aktarım

## Kullanım

Kurulum gerekmez. `index.html` dosyasını tarayıcıda aç (3B için internet bağlantısı gerekir — Three.js CDN'den yüklenir).

## Teknoloji

Saf HTML/CSS/JavaScript + [Three.js](https://threejs.org) r147.
