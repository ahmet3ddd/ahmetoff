1. Kemer Tipi Seçin

Sol panelden Tek Merkezli Teğet Kemer veya Penci Kemer seçin. Referans görsel otomatik değişir.

2. Parametreleri Ayarlayın

  • Mesafe: Toplam kemer genişliği (orijinal scripteğin p1–p2 mesafesi).
  • Böl: Yan yana kaç kemer çizileceği.
  • Başlık: Kemerler arasındaki sütun/başlık genişliği.
  • Kalınlık: Kemer taş profilinin kalınlığı (MaxScript applyOffset).
  • Extrude Derinlik: 3D STL için Z ekseni derinliği.

3. Görünümler

Sol viewport 2D (profil çizimi), sağ viewport 3D (Three.js). 3D'de fareyle: sol tuş orbit, orta tuş pan, tekerlek zoom. PNG kaydı için önce ilgili viewport'a tıklayın (sarı çerçeve aktif olur).

4. Export

  • STL: 3D mesh (Kalınlık > 0 ve Extrude Derinlik > 0 gerekli).
  • DXF: 2D vektör çizim (AutoCAD/QCAD/LibreCAD ile uyumlu).
  • PNG: Aktif viewport'un (2D veya 3D) görüntüsü.

3ds Max DXF Import

Import penceresinde Weld vertices seçeneğini işaretleyin; bölmeler tek spline olarak birleşir.
