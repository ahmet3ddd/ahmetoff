Bu repository birden fazla projeyi barındırmak için hazırlanmış monorepo iskeletidir.

Başlamak

  1. projects/ dizinine gidin.
  2. Yeni bir proje eklemek için `projects/<project-name>/` klasörü oluşturun ve dosyalarınızı buraya kopyalayın.
  3. README_TEMPLATE.md dosyasını kullanarak her proje için README oluşturun.

Daha fazla bilgi için repo README dosyasına bakın.

Repository public — herkes görebilir ve kullanabilir.
